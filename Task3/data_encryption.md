# Решение Задания 3: Оценка Data Encryption at Rest and In Transit

## Классификация данных и инструменты защиты

| Данные | В чём необходимость защиты | Инструменты защиты |
|--------|----------------------------|--------------------|
| **Медицинские данные (диагнозы, истории болезни, результаты анализов)** — At Rest | Утечка → нарушение врачебной тайны, штраф до 500 тыс. руб., репутационный ущерб, шантаж пациентов | Шифрование AES-256 (PostgreSQL pgcrypto), ABAC, аудит всех обращений |
| **Медицинские данные** — In Transit | Перехват → нарушение врачебной тайны, компрометация диагнозов | TLS 1.3, mutual TLS для сервисов |
| **Паспортные данные пациентов** — At Rest | Утечка → нарушение 152-ФЗ, штраф от РКН, иски пациентов | Шифрование AES-256 (pgcrypto), маскирование в UI |
| **Паспортные данные** — In Transit | Перехват → нарушение 152-ФЗ, кража личности | TLS 1.3, HSTS |
| **ФИО, телефоны, email, адреса** — At Rest | Утечка → спам, фишинг, нарушение 152-ФЗ | Шифрование AES-256, маскирование в API |
| **ФИО, телефоны, email, адреса** — In Transit | Перехват → нарушение приватности | TLS 1.3 |
| **Зарплаты сотрудников** — At Rest | Утечка → конфликты в коллективе, иски, шантаж | Шифрование AES-256, RBAC |
| **Зарплаты** — In Transit | Перехват → утечка финансовой информации | TLS 1.3, выделенные каналы |
| **Платёжные данные (карты)** — At Rest | Утечка → мошенничество, штраф PCI DSS до $100,000 | Tokenization, AES-256 |
| **Платёжные данные** — In Transit | Перехват → кража денег, компрометация карт | TLS 1.3, PCI DSS |
| **Учётные данные AD (хэши паролей)** — At Rest | Кража → компрометация всей сети домена | BitLocker, защита контроллера домена |
| **Учётные данные** — In Transit | Перехват → компрометация учётных записей | LDAPS, Kerberos |
| **Ключи шифрования (KMS)** — At Rest | Кража → расшифровка всех данных системы | HSM (YubiHSM 2), разделение доступа |
| **Ключи шифрования** — In Transit | Перехват → компрометация всех ключей | mTLS, защищённые каналы |
| **Согласия пациентов на обработку ПДн** — At Rest | Потеря → нарушение 152-ФЗ, невозможность доказать согласие | Шифрование AES-256, репликация |
| **Согласия** — In Transit | Перехват → манипуляции с согласиями | TLS 1.3 |
| **Бухгалтерские проводки** — At Rest | Утечка → налоговая проверка, коммерческая тайна | Шифрование (1С встроенное), RBAC |
| **Бухгалтерские проводки** — In Transit | Перехват → коммерческая тайна, анализ финансов | TLS 1.3 |
| **Журналы аудита (Audit Log)** — At Rest | Модификация → сокрытие следов взлома | WORM, BitLocker, целостность |
| **Журналы аудита** — In Transit | Перехват → анализ уязвимостей системы | TLS 1.3 |
| **Остатки ТМЦ на складе** — At Rest | Утечка → анализ закупок, коммерческая тайна | RBAC, шифрование |
| **Остатки ТМЦ** — In Transit | Перехват → коммерческая тайна | TLS 1.3 |
| **Расписания врачей** — At Rest | Утечка → анализ загрузки, планирование атак | RBAC |
| **Расписания** — In Transit | Перехват → анализ работы клиники | TLS 1.3 |
| **Прайс-лист на услуги** — At Rest | Публичные данные, защита не требуется | Без шифрования |
| **Прайс-лист** — In Transit | Целостность данных | TLS 1.3 |

## Итоговая статистика

- **Всего категорий данных:** 26
- **Требуют шифрования At Rest:** 14 категорий (P1, P2)
- **Требуют шифрования In Transit:** 25 категорий (все кроме публичных)
- **Критичные данные (P1):** 8 категорий — медицинская тайна, паспортные данные, зарплаты, платёжные данные, ключи шифрования
- **Высокие риски (P2):** 10 категорий — ПДн, финансовые данные, согласия
- **Средние риски (P3):** 7 категорий — служебные данные, журналы, ТМЦ
- **Публичные (P4):** 1 категория — прайс-лист

## Соответствие требованиям

| Требование | Реализация |
|------------|------------|
| **152-ФЗ, ст. 19** (шифрование ПДн) | AES-256 (pgcrypto), TLS 1.3 |
| **152-ФЗ, ст. 20** (трансграничная передача) | Данные в РФ, TLS |
| **PCI DSS 4.0** (платёжные данные) | Tokenization, TLS 1.3 |
| **ISO 27001 A.10** (криптография) | Vault, AES-256, TLS 1.3 |
